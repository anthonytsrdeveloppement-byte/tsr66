# Le dossier de la checklist

Tout ce qu'on contrôle, et tout ce qui a été contrôlé, se trouve ici. Les règles viennent du PRD (section 2.3).

| Fichier | À quoi il sert | Quand on s'en sert |
|---|---|---|
| `1-demarrage.md` | Les 7 contrôles avant de toucher au code (D1 à D7) | Au début de chaque session : feu vert ou rouge |
| `2-fin-de-session.md` | Les 6 contrôles avant de clôturer (F1 à F6) | À la fin de chaque session |
| `3-fin-de-lot.md` | Les 7 contrôles qui terminent un lot (L1 à L7) | À la dernière session de chaque lot |
| `4-controles-du-site.md` | Chaque exigence du PRD transformée en contrôle (C01, C02…). Un contrôle s'active dès que la fonction existe, puis il est rejoué à chaque session | À chaque session (F1) et à chaque envoi sur GitHub |
| `historique.md` | Une ligne par session et par fin de lot : les feux, les contrôles faits, les points importants | Complété à chaque fin de session |
| `sessions/` | Le rapport détaillé de chaque session, avec la preuve de chaque contrôle | Un rapport par session |

**Pour vérifier à tout moment**, il suffit de demander :
- « contrôle la checklist » : tout est rejoué ;
- « contrôle le point F3 » ou « contrôle le point C23 » : un seul point est rejoué ;
- « montre l'historique » : ce qui a été contrôlé, quand, et avec quel résultat.
